# Taller GitHub

## Descripción

Este repositorio fue creado para realizar el taller individual sobre GitHub y control de versiones.

## Proyecto

El proyecto desarrollado es una calculadora básica en Python.

La calculadora permite realizar:

- Sumas
- Restas
- Multiplicaciones
- Divisiones

## Estructura del repositorio

- README.md
- proyecto/calculadora.py
- documentacion/descripcion.txt

## Autor

Juan David García

## Objetivo

Aprender a utilizar GitHub para almacenar archivos, realizar cambios, registrar versiones y organizar un proyecto de programación.
